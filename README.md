# COVID-19 Data Analysis Dashboard

An end-to-end **SQL and Tableau data analytics project** analyzing global COVID-19 cases, deaths, infections, and vaccination progress. The project transforms raw pandemic data into structured metrics and interactive visualizations for comparing countries, continents, and global trends.

## Project Overview

This project combines **Microsoft SQL Server** for data exploration and transformation with **Tableau** for interactive dashboard development.

### Key Analysis
- Global COVID-19 cases, deaths, and death percentage
- Country-level infection rates and population impact
- Countries with the highest reported death counts
- Continent-level death comparisons
- Daily global cases and deaths
- Vaccination progress and percentage of population vaccinated
- Running vaccination totals using SQL window functions
- Prepared analytical queries for Tableau visualizations

## Technical Skills

**Languages & Tools:** SQL, Microsoft SQL Server, Tableau  
**SQL Concepts:** Joins, CTEs, Temporary Tables, Views, Window Functions, Aggregations, Data Transformation  
**Analytics:** KPI computation, trend analysis, country/continent comparison, vaccination analysis, data visualization

## Project Workflow

1. **Data Exploration** — Queried COVID-19 deaths and vaccination datasets.
2. **Data Transformation** — Calculated infection rates, death percentages, running vaccination totals, and population-level metrics.
3. **SQL Analysis** — Used joins, CTEs, temporary tables, views, and window functions for analytical processing.
4. **Visualization** — Built Tableau dashboards to communicate global and country-level COVID-19 trends.
5. **Insight Generation** — Compared geographic trends and vaccination progress to support data-driven interpretation.
